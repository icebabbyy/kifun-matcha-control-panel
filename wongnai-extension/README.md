# HAPPIHAUS · KIFUN MATCHA — Wongnai & LINE MAN Auto Sync Extension (v3.0)

ส่วนขยาย Google Chrome สำหรับดึงยอดขายจากหน้าเว็บ **Wongnai Merchant Portal** (`merchant.wongnai.com`) เพื่อนำไปตัดสต็อกผงชา, นม, แพ็กเกจจิ้ง และขนมใน **Supabase Database** โดยอัตโนมัติ

---

### วิธีอัปเดต / โหลดใช้งานใน Google Chrome:

1. เปิดเบราว์เซอร์ Google Chrome แล้วไปที่: `chrome://extensions`
2. ตรวจสอบว่าเปิดสวิตช์ **"โหมดนักพัฒนาซอฟต์แวร์" (Developer mode)** ที่มุมขวาบน
3. หากเคยโหลดไว้แล้ว: กดปุ่ม **"โหลดซ้ำ" (Reload 🔄)** ที่การ์ด Extension `KIFUN MATCHA`
   *(หรือถ้าลงใหม่ ให้กด "โหลดส่วนขยายที่คลายการบีบอัดแล้ว" (Load unpacked) แล้วเลือกโฟลเดอร์ `wongnai-extension`)*
4. กลับไปที่แท็บ **Wongnai Merchant Portal** แล้วกด **รีเฟรชหน้าเว็บ (F5)** 1 ครั้ง

---

### วิธีใช้งาน & คำแนะนำเมื่อขึ้น "ไม่พบรายการเมนูในหน้านี้":

1. **สาเหตุที่ขึ้น "ไม่พบรายการเมนูในหน้านี้":**
   - **หน้ารายงานการขาย (`/report/sales`)**: หน้านี้เป็นกราฟสรุปยอดขายรวม ไม่ได้มีชื่อเมนูแยกแก้ว
   - **ช่วงวันที่ไม่มีออเดอร์ (`0 แก้ว`)**: หากเลือกช่วงวันที่ร้านยังไม่มีออเดอร์สำเร็จ ตารางจะว่างเปล่า (`อันดับสินค้าขายดีจะแสดงตรงนี้`) ระบบจึงไม่มีรายการให้อ่าน

2. **วิธีซิงก์ออเดอร์จริง:**
   - **วิธีที่ 1 (สแกนจากรายงาน):** ไปที่เมนูซ้ายมือ **"รายงาน Wongnai Merchant App"** → คลิก **"รายงานสินค้า"** (`/report/menus`) → เลือกช่วงวันที่มีออเดอร์ → กดปุ่ม **"🔄 สแกนออเดอร์"**
   - **วิธีที่ 2 (ตัดด่วนทันที):** ไม่ว่าจะอยู่หน้าไหน สามารถกดปุ่ม **"⚡ ตัดด่วน"** ที่มุมขวาล่าง → เลือกเมนู ผงชา นม และจำนวนแก้ว → กด **"บันทึกและตัดสต็อก"** ได้ทันทีโดยไม่ต้องรอตารางออเดอร์
